# Standoff 2 Telegram-магазин

Асинхронный Telegram-бот на Python 3.11+, aiogram 3 и SQLite. Магазин, ежедневные бонусы, розыгрыши, заявки на выдачу, задания и вся админ-панель работают внутри Telegram. Отдельного сайта или веб-админки нет.

## Важно о платежах и выдаче

- В боте продаётся цифровой товар. По [правилам Telegram для цифровых товаров](https://core.telegram.org/bots/payments-stars) оплата проводится исключительно Telegram Stars (`XTR`). Поэтому CryptoBot отключён и не предлагается пользователю.
- Бот принимает Stars через официальный Telegram Bot API, проверяет предварительный запрос оплаты, сумму, валюту, пользователя и уникальный charge ID. Платёж повторно не зачисляется.
- После оплаты бот создаёт заказ «оплачен, ожидает выдачи». Голду вручную передаёт администратор через внутриигровой рынок и только затем отмечает заказ выполненным.
- Выдача игровых предметов не автоматизирована. Бот никогда не запрашивает пароль от игрового аккаунта.

## Запуск на Replit

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. В Replit Secrets добавьте:
   - `BOT_TOKEN` — токен, выданный BotFather.
   - `ADMIN_ID` — ваш числовой Telegram ID.
3. Запустите workflow **Standoff 2 Telegram Bot**. При первом запуске бот создаст `data/standoff2.sqlite3` автоматически.
4. Откройте бота в Telegram и отправьте `/start`. Для админ-панели используйте `/admin`.

Не вставляйте токены в сообщения или исходный код. В этом проекте они читаются из переменных окружения.

## Локальный запуск

```bash
python3 -m pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN и ADMIN_ID в .env
python3 main.py
```

`DATABASE_PATH` по умолчанию равен `data/standoff2.sqlite3`. Время окончания розыгрышей задаётся в UTC в формате `ГГГГ-ММ-ДД ЧЧ:ММ`.

## Docker / VPS

```bash
cp .env.example .env
# Укажите BOT_TOKEN и ADMIN_ID в .env
docker compose up -d --build
```

SQLite находится в именованном Docker volume `bot-data`. Для резервной копии остановите контейнер и сохраните файл `data/standoff2.sqlite3` или экспортируйте volume; не копируйте SQLite-файл во время незавершённой записи без WAL-файлов.

## Админ-панель

Команда `/admin` доступна только Telegram ID из `ADMIN_ID`. ID перепроверяется при каждом действии админа. Внутри доступны статистика, пользователи и корректировка баланса с причиной, товары, заказы, платежи, бонусы, розыгрыши, заявки на выдачу, задания, рефералы, рассылка, настройки и журнал действий.

Для ручной выдачи заявки сначала одобряются (баланс списывается один раз), затем администратор вручную передаёт голду и отмечает заявку выполненной. Отклонение одобренной заявки возвращает баланс. Рассылка предварительно показывается администратору и отправляется с ограничением скорости.

## Проверки и ZIP

Запустить тесты:

```bash
python3 -m pytest -q
```

ZIP-архив исходного проекта можно пересобрать из корня:

```bash
zip -r standoff2-telegram-store.zip \
  main.py config.py database.py models.py states.py requirements.txt \
  .env.example .gitignore .dockerignore Dockerfile docker-compose.yml README.md \
  handlers keyboards services utils tests
```

Архив не содержит секретов, SQLite-базы, виртуального окружения или кэша.


### Настройка текстов кнопок
В админ-панели открой «✏️ Кнопки главного меню», выбери кнопку и отправь новый текст. Можно добавлять и менять emoji, например `📤 Вывод голды` или `💸 Вывести голду`. Отправь `-`, чтобы вернуть стандартный текст. Настройки сохраняются в `menu_labels.json`; файл и папка проекта должны быть доступны для записи. Для заданий подпись кнопки по умолчанию равна названию задания (например, `Подписка на канал`), а при необходимости её можно отдельно изменить в настройках задания.


### Главное меню пользователя
Постоянная клавиатура: «📁 Каталог», «📤 Вывести Gold», «👤 Профиль», «ℹ️ Информация». Пункты открывают каталог, заявку на вывод, баланс профиля и поддержку соответственно.
